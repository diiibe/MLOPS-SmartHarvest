# Italian Source Materials

This folder contains the original Italian-language technical reports produced
during the Machine Learning Operations (MLOps) course project at the University
of Trieste. They are preserved here as source materials for authenticity and
academic reference.

- **`pipeline_report.md`** — Detailed technical report on the pipeline
  architecture, feature engineering on temporal dynamics, clustering choices,
  validation, and conclusions. This is the primary source document for the
  English-language `TECHNICAL_REPORT.md` at the repository root.

- **`smartharvest_complete.md`** — System specification covering executive
  summary, prerequisites, per-dataset processing, data cube assembly, outputs,
  and operational checklists.

- **`data_strategy_report.md`** — Shorter document covering the data strategy
  and sensor selection rationale.

An English synthesis of these documents, restructured for international
readers and updated with explicit honesty about the absence of quantitative
validation, is available at the repository root as `TECHNICAL_REPORT.md`.
